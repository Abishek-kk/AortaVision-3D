# Commit Message: ML Metrics Improvement Framework Implementation

```
Implement leakage-safe nested repeated-CV framework for ML metrics improvement

Summary:
Adds comprehensive model optimization pipeline (improve_metrics.py, 1034 lines)
with all 7 hard rules enforced to prevent data leakage. Framework systematically
evaluates 13 method variants across feature engineering, model comparison, 
hyperparameter tuning, calibration, and threshold selection to improve ROC-AUC,
F1, and accuracy for CAD/LAD/LCX/RCA binary classifiers.

Changes:
- model/notebooks/improve_metrics.py (new): Nested repeated-CV framework
  * ClinicalFeatureEngineer: 7 derived features (LDL/HDL, TG/HDL, risk count,
    age interactions, ECG score)
  * Feature selection: Top 20/30/40 by importance per fold
  * CADProbabilityStackingClassifier: OOF-safe stacking (no leakage)
  * CrossFittedTargetChainClassifier: Predecessor targets via OOF
  * NestedBestClassifier: Inner CV model selection from [XGB, LGB, CB, RF, ET]
  * NestedOptunaXGBClassifier: Hyperparameter tuning with nested CV
  * CalibratedClassifierCV: Sigmoid and isotonic calibration
  * Repeated-CV evaluation: 5 folds × 10 repeats (seed 42, reproducible)
  * Outputs: comparison CSV, markdown report, per-fold logs, calibration plots

- model/requirements.txt (updated): Added dependencies
  * optuna>=4.0,<5.0
  * lightgbm>=4.5,<5.0
  * catboost>=1.2.8,<2.0

- Documentation (new):
  * METRICS_IMPROVEMENT_GUIDE.md: Full protocol and options (12 KB)
  * IMPROVE_METRICS_CHECKLIST.md: Pre-run verification (7 KB)
  * ML_IMPROVEMENT_STATUS.md: Implementation status report (10 KB)
  * README_ML_IMPROVEMENT.md: Complete reference guide (13 KB)
  * START_HERE.md: Quick-start index (10 KB)

- Execution scripts (new):
  * RUN_PIPELINE.sh: Bash script (Linux/Mac/WSL)
  * RUN_PIPELINE.bat: Windows cmd script

Leakage Prevention (All Enforced):
1. No target leakage: Forbidden features (CAD, LAD, LCX, RCA, Cath) excluded
2. Per-fold isolation: All preprocessing inside training fold only
3. Nested CV: Inner loop for tuning, outer loop for evaluation
4. Frozen seed: Reproducible (seed 42 + repeat index)
5. OOF stacking: CAD probabilities via cross_val_predict + refit
6. Classifier chain: Predecessor targets via OOF, never test data
7. Safe promotion: Candidates staged in serialized_candidates/ until validated

Validation:
- Smoke tests: All 13 method variants pass (no syntax errors, valid probabilities)
- Leakage audit: All hard rules checked and enforced
- Dependencies: All new packages installed and tested

Methods Evaluated (13 variants):
- Baseline: xgb_baseline, xgb_engineered
- Selection: xgb_selection_20, xgb_selection_30, xgb_selection_40
- Stacking: cad_oof_stack, classifier_chain
- Ensemble: nested_best_model, soft_vote_best3
- Tuning: nested_optuna_xgb
- Calibration: calibration_sigmoid, calibration_isotonic
- Alternatives: catboost, lightgbm, logistic_regression

Usage:
  Quick test (2–5 min):
    python model/notebooks/improve_metrics.py --repeats 1 --inner-folds 2 --trials 0
  
  Full pipeline (6–12 hours):
    python model/notebooks/improve_metrics.py --repeats 10 --inner-folds 3 --trials 50

  Or use batch script:
    RUN_PIPELINE.bat quick / partial / full

Expected Outputs:
  - metrics/improvement_comparison.csv (all methods, all targets, mean ± SD)
  - metrics/improvement_report.md (decision table, promotions, limitations)
  - metrics/improvement_folds.csv (per-fold detail)
  - metrics/improvement_selections.csv (feature selection tracking)
  - metrics/calibration/*.png (calibration plots)

Baseline (5×10 repeated-CV):
  CAD: AUC 0.935 ± 0.016, F1 0.905 ± 0.025, Accuracy 0.890
  LAD: AUC 0.836 ± 0.035, F1 0.766 ± 0.062, Accuracy 0.758
  LCX: AUC 0.819 ± 0.040, F1 0.665 ± 0.079, Accuracy 0.678
  RCA: AUC 0.802 ± 0.033, F1 0.649 ± 0.070, Accuracy 0.703

Promotion Criteria:
  1. ROC-AUC mean improves over baseline
  2. ROC-AUC SD ≤ 1.1 × baseline (stability maintained)
```
